Module Core Concept Explored Empirical Finding in Placement Dataset Production Impact
M1 The ML System Lifecycle 50,000 student records cleaned with strict training-serving split. Eliminates silent data-leakage bugs and ensures 100% reproducible preprocessing.

M3 Tree-Based Ensembles Gradient Boosting & XGBoost captured non-linear interactions between CGPA and coding scores. Tree ensembles outperform linear baselines by +1.56% on structured student data.

M5 Evaluation & Calibration Stratified 5-fold CV confirmed low variance; PR curves proved high precision on imbalanced splits. Calibrated probabilities allow colleges to trust predicted odds for career counseling.
M6 Production Engineering Pipeline packaged into self-contained .pkl artifacts served via REST endpoint. Ensures consistent transformation with zero training-serving skew under sub-5ms SLAs.
