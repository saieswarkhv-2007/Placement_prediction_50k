Module 2 Engineering

Data Preprocessing & Feature Engineering

The systematic transformation pipeline from raw student records into model-ready numerical feature tensors. Adhering to strict training-serving boundary discipline to eliminate leakage and skew.

1️⃣

Missing Value Imputation

Numerical attributes (Workshops, AptitudeTestScore, CodingTestScore) imputed via Median to preserve robustness against outliers. Categorical fields imputed with Mode.

2️⃣

Categorical Encoding

Nominal attributes (Gender, Stream, Specialisation, Hostel) transformed via One-Hot Encoding (handle_unknown='ignore') to prevent spurious ordinal biases.

3️⃣

Feature Standardization

Numerical columns scaled using StandardScaler ($z = \frac{x - \mu}{\sigma}$). Critical for gradient descent convergence in linear models, while tree models remain invariant.

4️⃣

Target Leakage Prevention

Strict exclusion of Salary Package (which only exists post-placement) and arbitrary identifiers (StudentID) to guarantee production validity.

Scikit-Learn Production Preprocessing Pipeline

This pipeline encapsulates both imputation and scaling inside a persistent ColumnTransformer, ensuring identical transformation during batch training and online single-student inference.

from sklearn.compose import ColumnTransformer from sklearn.pipeline import Pipeline from sklearn.impute import SimpleImputer from sklearn.preprocessing import StandardScaler, OneHotEncoder # Define numeric and categorical feature sets numeric_features = ['CGPA', 'HistoryOfBacklogs', 'Internships', 'CodingTestScore', 'AptitudeTestScore', ...] categorical_features = ['Gender', 'CollegeTier', 'Stream', 'Specialisation', 'Hostel', ...] # Build modular transformers num_transformer = Pipeline(steps=[ ('imputer', SimpleImputer(strategy='median')), ('scaler', StandardScaler()) ]) cat_transformer = Pipeline(steps=[ ('imputer', SimpleImputer(strategy='most_frequent')), ('ohe', OneHotEncoder(handle_unknown='ignore', sparse_output=False)) ]) # Assemble unified ColumnTransformer preprocessor = ColumnTransformer(transformers=[ ('num', num_transformer, numeric_features), ('cat', cat_transformer, categorical_features) ])
