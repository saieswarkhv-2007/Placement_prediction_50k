Module 2

M2. Supervised Learning — Linear Models at Depth

Linear & Logistic Regression revisited: Closed-form normal equations vs gradient descent, regularisation (Ridge L2, Lasso L1, Elastic Net), the sigmoid activation, and the hyperplane decision boundary.

Sigmoid Activation Function

Mapping linear combination $z = w^T X + b$ to probability space [0, 1]

Formula: $\sigma(z) = \frac{1}{1 + e^{-z}}$. Decision boundary set at $\sigma(z) = 0.5 \iff w^T X + b = 0$.

Binary Cross-Entropy Loss Dynamics

Log-loss penalties for correct and incorrect placement predictions

Loss $\mathcal{L} = -[y \log(\hat{y}) + (1-y)\log(1-\hat{y})]$. Heavy convex penalization when predicting 0 for placed students.

L1 vs L2 Regularization Geometry

Diamond (L1) vs Circle (L2) constraint regions explaining sparsity induction

Lasso (L1) corners intersect elliptical loss contours at zero axes, naturally selecting sparse feature subsets.

Gradient Descent Cost Convergence

Loss reduction across training epochs under batch gradient descent

StandardScaler ensures isotropic loss contours, accelerating gradient descent convergence.
Module 3

M3. Supervised Learning — Tree-Based Models

From greedy top-down recursive decision trees to modern ensemble workhorses: Random Forests bagging, AdaBoost, Gradient Boosting, and XGBoost. Interpreting feature importances on tabular datasets.

Decision Tree Architecture Diagram

Greedy axis-aligned splits optimizing Gini Impurity $I_G = 1 - \sum p_i^2$

Pre-pruned to max_depth=8 and min_samples_leaf=5 to avoid high-variance overfitting.

Random Forest Feature Importances

Mean Decrease in Impurity (MDI) across 80 de-correlated trees

CGPA, CodingTestScore, and Internships dominate split value reductions.

🌲 Decision Tree

Single interpretable tree. Fast and transparent, but prone to high variance without aggressive pruning.

🌳 Random Forest

Bagging (bootstrap aggregation) with random feature subsampling ($\sqrt{p}$). Drastically dampens individual tree variance.

🚀 Gradient Boosting & XGBoost

Functional gradient descent iteratively correcting residual errors. Industrial standard workhorses for tabular Kaggle data.

M6. ML Engineering — From Notebook to Production

Bridging the notebook-to-production gap: Serialization pitfalls, pipeline encapsulation, low-latency serving, and data drift monitoring in live inference systems.

Production Serving Latency Benchmark

Inference duration per student request in milliseconds (ms)

Logistic Regression & Decision Trees achieve sub-millisecond inference; Ensembles execute in <3ms, well within SLA limits.

Production Serving & Skew Defense Checklist

  • ✅ Pipeline Encapsulation: Preprocessor + Estimator serialized together in .pkl to avoid missing-transform bugs.
  • ✅ Point-in-Time Correctness: Only features known prior to placement offer are fed into classifier.
  • ✅ Data Drift Defense: Online request distributions logged to prediction_history.json for periodic Kolmogorov-Smirnov drift testing.
  • ✅ Dual Prediction Architecture: Binary placement classification combined with secondary salary regression on positive predictions.
